# СБОРКА APK БЕЗ УСТАНОВКИ FLUTTER (20–30 минут)
# Через бесплатный облачный сервис Codemagic + GitHub

## ШАГ 1. Загрузите проект на GitHub (~10 минут)

1. Зайдите на github.com → зарегистрируйтесь (бесплатно).
2. Нажмите «New repository» → имя: avtopomoshnik → Public → Create.
3. На странице репозитория нажмите «uploading an existing file».
4. ПЕРЕТАЩИТЕ МЫШКОЙ в браузер ВСЕ СОДЕРЖИМОЕ папки avtopomoshnik:
      pubspec.yaml
      lib/main.dart
      android/ (всю папку целиком)
   Структура на GitHub должна быть:
      avtopomoshnik/
      ├── pubspec.yaml
      ├── lib/main.dart
      └── android/...
5. Нажмите «Commit changes».

## ШАГ 2. Соберите APK на Codemagic (~10 минут)

1. Зайдите на codemagic.io → «Sign up» → «Sign up with GitHub»
   (бесплатный тариф — 500 минут сборки в месяц, нам хватит с запасом).
2. «Add application» → выберите репозиторий avtopomoshnik →
   тип приложения: Flutter → Finish.
3. «Start new build» → в настройках сборки:
   - Platform: отметьте Android
   - Build type: APK (debug)   ← важно! Подпись debug — для теста идеально
4. Нажмите «Start build» и ждите 5–10 минут (зелёная галочка = успех).
5. Внизу страницы сборки — «Artifacts» → скачайте app-debug.apk.

## ШАГ 3. Установите на смартфон (~2 минуты)

1. Перекиньте app-debug.apk на телефон любым способом:
   Telegram («Избранное»), USB-кабель, Google Диск, почта.
2. На телефоне откройте APK → система предложит разрешить установку
   из этого источника → разрешите → «Установить».
   Требуется Android 5.0 и новее (подавляющее большинство телефонов).

## ШАГ 4. Чек-лист теста (5 минут)

[ ] Открываются все 5 разделов с главного экрана
[ ] «Мой гараж» → добавьте авто с датами ТО/страховки/переобувки
    → цветные индикаторы дней отображаются
[ ] Полностью закройте приложение (уберите из памяти) → откройте снова
    → авто СОХРАНИЛОСЬ (это проверка локального хранилища)
[ ] «ОСАГО» → двигайте слайдеры возраста/стажа/мощности
    → цена пересчитывается
[ ] «Налог» → смените регион → сумма меняется
[ ] «Штрафы» → введите любой номер → появляется демо-диалог
[ ] Кнопки партнёрских предложений открывают браузер
    (ссылки пока заглушки — это нормально)
[ ] Ничего не обрезано, нет налезающих элементов, иконка синяя с буквой A

## Если сборка на Codemagic упала с ошибкой

Не паникуйте — 99% таких проблем решаются за минуту.
Скопируйте текст ошибки из лога и пришлите мне — я скажу,
что поправить (обычно это версия Flutter или строка в gradle-файле).

## ВАЖНО на будущее

- applicationId сейчас com.example.avtopomoshnik — перед публикацией
  в RuStore замените на свой уникальный (например, ru.vashfamiliya.avtopomoshnik)
  в android/app/build.gradle.kts.
- Перед RuStore создайте СВОЙ ключ подписи вместо debug —
  иначе потом нельзя будет обновлять приложение.
- В коде (lib/main.dart, начало файла) всё ещё стоят заглушки
  партнёрских ссылок — вставьте свои перед публикацией.

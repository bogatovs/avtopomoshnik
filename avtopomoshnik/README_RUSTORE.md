# АВТОПОМОЩНИК — инструкция от идеи до публикации в RuStore

Приложение: штрафы ГИБДД, транспортный налог, ОСАГО-калькулятор,
«Мой гараж» (напоминания), партнёрские предложения.
Заработок: CPA-партнёрские программы (без ИП и без комиссии RuStore).

================================================================
ШАГ 1. УСТАНОВКА FLUTTER (один раз, ~30 минут)
================================================================
1. Скачайте Flutter SDK: https://docs.flutter.dev/get-started/install
   (Windows: распакуйте в C:\flutter, добавьте C:\flutter\bin в PATH)
2. Проверьте: в командной строке выполните
      flutter doctor
   и устраните отмеченные проблемы (нужен Android Studio).

================================================================
ШАГ 2. СОЗДАНИЕ ПРОЕКТА И ЗАМЕНА КОДА (~10 минут)
================================================================
1. В командной строке:
      flutter create avtopomoshnik
      cd avtopomoshnik
2. Откройте папку в Android Studio.
3. Замените файл lib/main.dart на приложенный main.dart
   (удалите всё содержимое, вставьте целиком).
4. Замените pubspec.yaml на приложенный.
5. В терминале Android Studio выполните:
      flutter pub get
6. Запустите на телефоне (включите отладку по USB) или эмуляторе:
      flutter run

================================================================
ШАГ 3. ВСТАВЬТЕ СВОИ ПАРТНЁРСКИЕ ССЫЛКИ (~15 минут)
================================================================
В файле lib/main.dart найдите блок «ПАРТНЁРСКИЕ ССЫЛКИ»
(в самом начале файла, класс PartnerLinks) и замените
«https://ВАША_ССЫЛКА_...» на ваши ссылки из CPA-сетей:
  - osago          — ОСАГО (выплата 150–600 ₽ за оформленный полис)
  - kreditAvto     — автокредит (500–3000 ₽ за выданный кредит)
  - proverkaVin    — проверка авто по VIN (100–500 ₽)
  - shtrafyOplata  — оплата штрафов (10–15% с платежа)
  - shiny          — шины/шиномонтаж (3–8% с заказа)

Совет: берите офферы из нескольких сетей (Admitad, CityAds, M1-Shop,
ActionPay и подобных) — у разных сетей разные ставки и EPC.

================================================================
ШАГ 4. (ОПЦИОНАЛЬНО) ПОДКЛЮЧЕНИЕ РЕАЛЬНОЙ ПРОВЕРКИ ШТРАФОВ
================================================================
В экране «Штрафы ГИБДД» сейчас демо-заглушка (метод _check()).
Чтобы показывать реальные штрафы:
1. Купите доступ к API агрегатора штрафов
   (поищите «API проверки штрафов ГИБДД», обычно 1–3 ₽/запрос,
   оплата за пакет запросов).
2. Добавьте пакет http: в pubspec.yaml в dependencies добавьте строку
      http: ^1.2.0
   затем выполните flutter pub get
3. В методе _check() замените имитацию на POST-запрос к API
   с полями «госномер» и «номер СТС», покажите полученный
   список штрафов вместо диалога.
4. Для Android добавьте в android/app/src/main/AndroidManifest.xml
   в тег <manifest> строку:
      <uses-permission android:name="android.permission.INTERNET"/>
ВАЖНО: версия без подключения API тоже проходит модерацию —
просто честно подпишите в описании «проверка штрафов скоро».

================================================================
ШАГ 5. ПОДПИСЬ И СБОРКА APK (~20 минут)
================================================================
Самый простой способ — через Android Studio:
1. Build → Generate Signed Bundle / APK → APK → Next
2. Create new... → создайте keystore (сохраните файл .jks и пароли
   ОБЯЗАТЕЛЬНО — без них обновления невозможны!)
3. Выберите release → Create.
Готовый APK: avtopomoshnik/build/app/outputs/flutter-apk/app-release.apk

ВАЖНО: файл ключа и пароли храните в надёжном месте —
потеряете — не сможете выпускать обновления под тем же приложением.

================================================================
ШАГ 6. ПУБЛИКАЦИЯ В RUSTORE (~1–3 дня на модерацию)
================================================================
1. Откройте консоль: https://console.rustore.ru
2. Зарегистрируйтесь как разработчик (Яндекс ID).
   Публикация бесплатных приложений доступна физлицу.
3. Создайте приложение → заполните поля (тексты ниже).
4. Загрузите APK из шага 5.
5. Обязательно укажите ссылку на политику конфиденциальности.
   Варианты бесплатного размещения:
   - любой хостинг статики (GitHub Pages, Netlify): выложите
     приложенный файл PRIVACY_POLICY.txt как страницу;
   - или короткая страница-лендинг приложения.
   В тексте политики замените [ВАШ_EMAIL] на свой.
6. Возрастное ограничение: 16+ (упоминание кредитных предложений)
   или 12+, если уберёте кредитный оффер.
7. Отправьте на модерацию. Обычно 1–3 рабочих дня.

ГОТОВЫЕ ТЕКСТЫ ДЛЯ КАРТОЧКИ RUSTORE
================================================================
Название: Автопомощник — штрафы, налог, ОСАГО

Короткое описание (до 80 знаков):
Штрафы ГИБДД, транспортный налог, ОСАГО и напоминания для авто

Полное описание:
Автопомощник — бесплатное приложение для автовладельцев РФ.

• Штрафы ГИБДД — проверка по госномеру и СТС,
  оплата со скидкой 50%
• Транспортный налог — расчёт по региону и мощности
• ОСАГО-калькулятор — оценка стоимости полиса с учётом КБМ
• Мой гараж — напоминания о ТО, окончании страховки
  и сезонной переобувке
• Выгодные предложения для автовладельцев

Все данные хранятся только на вашем устройстве.
Приложение не требует регистрации и работает оффлайн
(кроме переходов к сервисам-партнёрам).

Ключевые слова (для поля тегов/категорий):
штрафы гибдд, проверка штрафов, транспортный налог,
осаго калькулятор, стоимость осаго, напоминание то,
техосмотр, страховка авто, переобувка, автовладельцу

КАК БУДЕТ РАСТИ ЗАРАБОТОК
================================================================
Этап 1 (сейчас): партнёрки — каждый переход/оформление
  приносит 100–3000 ₽. С 100–300 установок в месяц реально
  3–15 тыс. ₽, дальше — масштабирование трафика.
Этап 2 (через 1–2 месяца): купить API штрафов → пользователи
  начнут возвращаться каждую неделю «провериться» — рост удержания.
Этап 3 (когда откроете ИП): подключить Pay SDK RuStore —
  подписка «Про» без рекламы + мониторинг штрафов автоматически
  (99–199 ₽/мес). Комиссия RuStore 15%.
